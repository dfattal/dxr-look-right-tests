Inline-3D look-right tests

Pages built by Haiku, Sonnet and Opus in a clean room from the SDK repo alone. baseline = docs at 1.46.0; newdocs = the first draft of docs/making-3d-look-right.md (its depth budget was too tight, so expect these to be flatter). Numbers: headless judge, in-front p2 / behind p98 disparity, % of tile width (minus = in front of the glass). Open them in the DisplayXR Browser and tell me which look right, too deep, or too flat.

Calibration

Depth calibration page: step a crate and a backdrop through depths (tile heights, with % of width) and note where doubling or discomfort starts.
